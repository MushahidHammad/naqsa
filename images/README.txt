NAQSA website: where to put your photos
=======================================
Save photos in this folder with EXACTLY these names (.jpg), all lowercase.
"Shows placeholder" = a colour block appears until you add the photo.
"Optional" = hidden until you add the photo (nothing empty appears).

HOME
  home-banner.jpg      wide band under the statement     2400 x 1000   shows placeholder
  home-2.jpg           gallery, left                      1600 x 1200   optional
  home-3.jpg           gallery, right                     1600 x 1200   optional
ABOUT
  founder.jpg          portrait of the founder (real photo, not stock)   1200 x 1500   shows placeholder
  about-2.jpg          wide band between story and values  2400 x 800    optional
SERVICES
  services-banner.jpg  banner under the title             2400 x 800    shows placeholder
  services-2.jpg       below the services list, left      1600 x 1200   optional
  services-3.jpg       below the services list, right     1600 x 1200   optional
PROCESS
  process-banner.jpg   banner under the title             2400 x 800    shows placeholder
  process-2.jpg        wide band before the final call    2400 x 800    optional
BLOG (also used as the cover at the top of each article)
  blog-1.jpg, blog-2.jpg, blog-3.jpg                      1600 x 1200   shows placeholder
CONTACT
  contact.jpg          under the studio details           1600 x 1200   optional

Tips
- Keep each file under about 300 KB (compress at squoosh.app or tinypng.com).
- Use free-licence photos (Unsplash, Pexels, Pixabay). Do not present stock photos as NAQSA's own projects.
- Update the alt text in the HTML to describe each photo (search for "IMAGE SLOT").
