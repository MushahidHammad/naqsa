NAQSA website: where to put your photos
=======================================
Save photos in this folder with EXACTLY these names (.jpg). Until a file exists, the site shows a colour placeholder.

home-banner.jpg      Home page wide band        2400 x 1000 px   calm interior / light / texture
services-banner.jpg  Services page banner       2400 x 800 px    interior details: stone, timber, linen
process-banner.jpg   Process page banner        2400 x 800 px    drawings, sketching, planning
founder.jpg          About page portrait        1200 x 1500 px   a real photo of the founder (not stock)
blog-1.jpg           Blog cover, article 1      1600 x 1200 px   architect's desk, drawings
blog-2.jpg           Blog cover, article 2      1600 x 1200 px   sunlight, window, shadow
blog-3.jpg           Blog cover, article 3      1600 x 1200 px   house plan model / planning

Tips
- Keep each file under about 300 KB (compress at squoosh.app or tinypng.com).
- Use free-licence photos (Unsplash, Pexels, Pixabay) and do not present stock photos as NAQSA's own projects.
- Update the alt text in the HTML to describe each photo (search for "IMAGE SLOT").
- Blog covers also appear automatically at the top of each article.
